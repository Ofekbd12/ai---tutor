# 🧠 AI Tutor

An AI-powered tutoring platform designed to ensure continuous learning for students during wartime, enabling access to educational support while I serve on active military duty.

---

##  Overview

During a period of instability and limited availability for in-person teaching, I developed this platform to provide my students with a reliable and scalable learning solution.

AI Tutor allows students to ask questions, receive explanations, and continue progressing independently, bridging the gap created by real-world constraints.

This project combines practical problem-solving with modern AI capabilities to deliver an accessible and adaptive educational experience.



##  Key Features

-  AI-driven tutoring and explanations  
-  Real-time interaction with students  
-  Continuous learning support in disrupted environments  
-  Modular and extensible architecture  
-  Designed for scalability and future integrations  


##  Tech Stack

- **Backend:** Python  
- **Frontend:** JavaScript (Node.js environment)  
- **AI Integration:** External LLM API  
- **Environment Management:** `.env` configuration  
- **Version Control:** Git & GitHub
